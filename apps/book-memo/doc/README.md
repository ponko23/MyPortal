# book-memo プロジェクトボード

`.github/extensions/myportal-book-memo-planner/` のカンバンキャンバスで、book-memo の要件と作業を整理します。ボードの目的とカードは [`usage-plan.json`](./usage-plan.json) に保存され、リポジトリで共有・編集できます。

## 列

- **未整理**: 追加したばかりの要件・利用場面・タスク
- **着手可能**: 内容が明確で、作業を始められるカード
- **進行中**: 現在作業しているカード
- **保留・要確認**: 仕様判断など、決定待ちのカード
- **完了**: 作業が完了したカード

## カード

- **機能**は親カードとして、その下に **タスク** や **仕様判断** を子カードとして関連づけます。
- **利用場面**は機能を検討するときの文脈として独立したカードにします。
- 作業状態は列で、優先度は優先度フィールドで、機能分野などはラベルで表します。

JSON の `format` と `version` は保存形式を示します。旧形式の用途計画は初回読み込み時にカンバンへ移行します。未対応の形式や破損したデータは自動で上書きせず、キャンバスにエラーを表示します。
